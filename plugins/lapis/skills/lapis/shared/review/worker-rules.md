# Rules every delegated task carries

A task you hand to another agent (a rough worker, a critic, a builder, a reviewer) starts blank: it has not read the root
skill, so it does not know these rules unless the task says them. Put the lines under **The rules** into every delegated
task verbatim. `lapis-design` prints them where it names a delegation (`diverge`, `critic packet`, `slice`), and checks what
it can afterwards (see **What is checked, and what is not**).

## The rules

- Do not read the source of `lapis-design` (the files under `lapis_design/`, an `import` of its modules in `python -c` or a script, `inspect.getsource`, or a listing of its installed package folder) to argue with a finding or to make a page or a record pass it. The commands are the interface: `lapis-design ...`, `lazuli ...`, `--help`, and the installed skill guides. Put a finding you believe is wrong in `.lapis/disputes/<task>.yaml` (`shared/review/disputes.schema.yaml`): a critic re-judges it on the captures, the owner sees both, and a dispute does not clear it.
- Stop a process only by a process id a command recorded (such as the one in `.lapis/logs/<task>.<step>.pid`). Never stop one by pattern: no `pkill`, no `killall`, no `pgrep`, `pidof`, `lsof`, or `ps` piped or substituted into `kill`, with or without `-f`. Other work shares the machine, and a pattern reaches it.
- Return check results as the report's path and the summary the check printed (verdict, scope, counts, new and changed findings with ids, blockers, limits, build id), never the raw extract, session, report, DOM, or log pasted into a message. Leave the raw files where the check wrote them, and run a check once per build: a repeat of the same build prints `cache hit` and adds nothing.
- Say in your last message which of these you could not keep, and why.

## What is checked, and what is not

- The pre-write hook (`pre-write`, which also receives `Bash` calls) refuses a shell command that stops a process by pattern, in a project that has a plan, in the main session and in every subagent of a harness whose hooks run for subagents (Claude Code does; the extension for Oh-My-Pi and pi sends `bash` calls to the same hook). A command that kills by pattern through a script or an interpreter (`python -c`, a shell script file) is not seen.
- A `SubagentStop` hook (Claude Code) and Antigravity's `stop` hook read the agent's own transcript, and `lapis-design worker check --task <task> --transcript <file>` reads any transcript file you give it. Each `pkill`, `killall`, or kill by pattern, and each tool call that read the source of `lapis-design`, becomes a line of `.lapis/state/<task>.workers.json` and of the owner block's integrity section. A source read is a path under `lapis_design/` (any module: `brief`, `next_step`, `requirements`, `direction`, `lint`, `render`, and the rest), a listing of the installed package folder, `from lapis_design import ...` or `import lapis_design[.module]` or `lapis_design.<module>` in code, or `inspect.getsource` (and `getfile`, `__file__`) of it; the finding names the module and the way (`path`, `package-dir`, `import`, `getsource`). Running the CLI (`lapis-design ...`, `lazuli ...`, `python -m lapis_design...`, `--help`) and reading the installed skill guides are not source reads. Reading is only recorded, never refused: the hook cannot tell a worker arguing with a finding from a person working on the checker (whose own edits under `lapis_design/` are recorded too).
- Antigravity's `stop` hook reads the transcript for every Stop, in the person's conversation and in a subagent's (the first row's `source` tells them apart; the owner block names which), in a project that has a plan. A Stop that names no transcript, or a transcript that cannot be read or holds no JSON row, is recorded as a limit in the same file and shown in the owner block; it is not a pass.
- Not checked: a harness that gives the CLI no transcript (Codex, Hermes), reads in the main session of a harness other than Antigravity, source read through a command the scanner does not parse (a script file you only run, a command that builds the path), and a transcript format the scanner does not parse. There the rule rests on this text and on the critic's question: ask the maker which delegated work read `lapis-design` source or stopped a process, and put the answer in a finding when it did.
